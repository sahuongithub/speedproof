Where these came from

None was invented to be caught. Each is a failure that a published benchmark documented in its own papers.

A real optimisation: ask forgiveness, not permission — chosen by measuring seven candidates. Four were slower than the code they replaced, and one that was faster in the measured region needed an import that cost more than it saved.

Computes the answer before the measurement starts — caching and persistent state accounted for 14 of 18 hacks in one published manual review.

Very fast, and wrong — two of the four published benchmarks compare no outputs at all.

Returns a promise instead of a result — one published benchmark documents an agent deferring matrix construction past its timed region.

Cheaper arithmetic, quietly less accurate — the class of fault that generic mutation operators do not produce, and that a tolerance-based check would accept.

speedproof — an agent that makes code faster, and a harness that can prove it did.
